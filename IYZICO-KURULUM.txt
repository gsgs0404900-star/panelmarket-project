PANELMARKET - IYZICO KURULUMU

HTTP 500/503 hatasının temel nedeni .env dosyasında iyzico anahtarlarının bulunmamasıdır.

1) .env.example dosyasını .env olarak kopyalayın.
2) iyzico Sandbox hesabınızdan şu bilgileri girin:
   IYZICO_API_KEY=...
   IYZICO_SECRET_KEY=...
   IYZICO_BASE_URL=https://sandbox-api.iyzipay.com
3) IYZICO_CALLBACK_URL alanını gerçek HTTPS alan adınızla doldurun.
   localhost callback adresi canlı iyzico doğrulaması için yeterli değildir.
4) Terminalde:
   npm install
   npm start
5) Tarayıcı:
   http://localhost:3000/payment.html

Güvenlik:
- API anahtarlarını frontend'e koymayın.
- .env dosyasını paylaşmayın veya GitHub'a yüklemeyin.
- Gerçek teslimatı yalnızca iyzico tarafından doğrulanmış SUCCESS sonucu sonrasında açın.
