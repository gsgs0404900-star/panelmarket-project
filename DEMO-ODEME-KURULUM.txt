PANELMARKET DEMO ODEME KURULUMU

1) Bu sürüm gerçek iyzico kullanmaz ve API Key istemez.
2) Terminalde klasöre girin:
   npm install
   npm start
3) Tarayıcıdan açın:
   http://localhost:3000/payment.html
4) Demo kart numarası: 4242 4242 4242 4242
5) Demo bakiye ürün fiyatına eşit veya yüksekse indirme butonu görünür.
6) Gerçek kart bilgilerini kullanmayın. Bu sistem sadece demodur.
